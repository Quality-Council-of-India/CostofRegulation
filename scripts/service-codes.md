# Canonical license/service codes (26)

Use these exact codes and names in your output. The code after `_ED_` in each
filename identifies the service — map it using this table:

| Code | Service name |
|---|---|
| BPA | Building Plan Approval |
| FBPA | Factory Building Plan Approval |
| ECL | Electricity Connection |
| FNO | Fire NOC |
| FNOC | Fire NOC (Delhi's own filename variant — same service as FNO) |
| RFNO | Renewal of Fire NOC |
| RFN | Renewal of Fire NOC (same as RFNO — treat identically) |
| GST | GST Registration |
| LEM | Legal Metrology |
| TFG | GST Tax Filing |
| TRG | GST Tax Refund |
| WAC | Water Connection |
| RSE | Registration under Shops & Establishment |
| FAL | Factory License |
| RFAL | Renewal of Factory License |
| CTE | Consent to Establish |
| CTO | Consent to Operate |
| RCTO | Renewal of Consent to Operate |
| LA | Land Allotment (a SERVICE code — do not confuse with the Ladakh STATE code, also "LA"; which one applies is always clear from context: a state folder's own files never use its own state code as a service code) |
| TLA | Trade License — Approval |
| TLR | Trade License — Renewal |
| ENCL | Environmental Clearance |
| OC | Occupancy Certificate |
| BMPA | Boilers Manufacturer Permission Approval |
| APW | Authorization for Plastic Waste |
| ELD | Electrical Drawings |
| LR | Lift Registration |

A file like `AN_ED_BPA.docx` in the "Andaman and Nicobar Islands" folder is the
Expert Discussion for Building Plan Approval in that state/UT. The same codes apply
to FGD filenames (e.g. `AN_FGD_BPA.docx`), with RFN treated identically to RFNO
(both mean Renewal of Fire NOC).
